# Русская локализация

## Правила

Показываемый игроку текст пишется по-русски. Повторяемые элементы интерфейса
хранятся в таблице `localization.cpp` и извлекаются стабильным ключом через
`tr()`. Имена enum, ключи сохранений, форматные маркеры грамматики (`%U`,
`<attack>`) и идентификаторы статей энциклопедии не переводятся.

Ширина интерфейса — 30 тайлов, а не 30 байт. Для обрезки используется
`utf8_prefix()`: он никогда не разрезает UTF-8-последовательность. Количества
оформляются через `ru_plural()` с формами для 1, 2–4 и 5–20.

## Генерируемые файлы

`source.txt` — источник истины для `glbdef.h` и `glbdef.cpp`:

```sh
support/enummaker/enummaker source.txt
```

`encyclopedia.txt` — единственный источник истины для энциклопедии.
`encyclopedia.cpp` и `encyclopedia.h` **не редактируются вручную** и обновляются:

```sh
support/encyclopedia2c/encyclopedia2c encyclopedia.txt
```

## Проверка строк

```sh
tools/check_untranslated.py
```

Проверка просматривает игровые модули, таблицу определений и энциклопедию и
отклоняет новые английские литералы. `tools/l10n_allowlist.txt` фиксирует
проверенные существующие технические термины, имена собственные, машинные
ключи и известный долг переноса старых фраз. Добавлять исключение можно только
после проверки назначения строки; снимок обновляется командой
`tools/check_untranslated.py --update`.
